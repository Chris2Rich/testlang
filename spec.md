Stack based language => data is added to stack with operators and when operator -ary is fullfilled, the operator will execute.
Arrays are declared with square brackets []
function parameters and higher order function logic can be delimeted with commas
array elements are delimited with commas
newlines create new statements
curly brackets create maps where each element is defined by a binding "=>" operator. these are then delimited with commas
=> binding operator declares identifiers. there is no syntax difference between functions and variables
